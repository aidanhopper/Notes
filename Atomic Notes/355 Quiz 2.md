# 355 Quiz 2

**What happens when you execute a program?**
A process is created and assigned a unique PID, and memory is allocated.
- Code Segment - holds the programs executable code.
- Data Segment - holds global and static variables.
- Stack - used for function calls, local variables and control flow.
- Heap - used for dynamic memory allocation

## TCO

When using recursion in a program it allocates stack frames for each function call. This ends up creating a lot of extra memory on the stack and can lead to a stack overflow. One way to solve this is using TCO (tail call optimization), where the result of the previous computation is stored in the recursive arguments.

A tail call is a function call that occurs as the last action of a function. The functions result is immediately returned to the caller without any further computation.

A TCO is a technique used by compilers or interpreters to optimize recursive function calls by reusing the current functions stack frame for a tail call, reducing the risk of stack overflow.

### Benefits of TCO

- prevents a stack overflow
- improves performance
- But... not all functions can be optimized with TCO, only tail recursive functions benefit from this optimization

## Lexical Analysis

One way to do lexical analysis is to use a **Context-Free Grammar (CFG)**, which is a set of rules that define the structure of a valid statement in a programming language. 

An abstract syntax tree is a tree representation of the syntactic structure of code. It captures the hierarchy of operations and expressions in the code.

## Interpreters & Compilers

three phases of an interpreter
- lexical analysis is the process of breaking down code into tokens
- syntax analysis checks if the structure of the code follows the grammar rules of the programming language.
- Semantic analysis ensures operations, variables, and references are contextually and logically accurate.

compilers do the same thing as interpreters with 2 more steps at the end
- Optimization
	- Peephole optimization: Where small group of instructions are replaced with more efficient ones.
	- Register allocation: assigning variables to processor registers to minimize memory access.
- Code generation to target language.
